# genesis-hacking

AI tools to make Rom hacks or cool stuff for Sega Genesis. Our first tool we
are going to try to create is a Sega Genesis sprite editor program.  I want
to be able to with a configuration file of where the sprites are in a game ROM
be able to change the contents of the sprite.  This configuration file will
probably be created from a reversing tool like Binary Ninja as a reverse
engineer determines where the artwork is stored in ROM memory
