# Preferred Languages

* C++ and C
* We will often write programs that act like Unix filters on stdin / stdout
* Python 3 is often a good choice (try to minimize dependencies)
* Avoid boost
* Prefer Qt for GUIs and other complex projects
* I prefer code be readable versus compact / terse code
* I love code to have debug output I can easily turn on and off
* I avoid quirky syntax features, lambda functions, etc
* I like C++ code to be C with classes.  Lightweight functional OO is nice too.
* I dislike interface heavy code
